# Data Minimisation: A Practical Privacy Guide

## Project Overview

This project was prepared as part of an internship assignment in Privacy and Data Protection for RedKross Research Foundation.

It focuses on data minimisation in student-facing services and research activities. The project explains how to collect only necessary personal information, communicate collection purposes, control access, establish retention periods and safely delete information when it is no longer needed.

## Objectives

- Understand the data minimisation principle.
- Identify unnecessary personal data fields.
- Promote transparency and responsible data handling.
- Provide a practical checklist for reviewing data collection.
- Demonstrate improvements through fictional before-and-after examples.

## Repository Contents

- `guide/` — Practical data minimisation guide.
- `checklist/` — Data minimisation review checklist.
- `examples/` — Three fictional before-and-after examples.
- `report/` — Mandatory technical report.
- `evidence/` — Relevant screenshots or supporting evidence, if available.

## Methodology

The project uses document-based research, established privacy guidance and fictional scenario analysis. The deliverables translate privacy principles into practical recommendations for students and research teams.

## How to Use the Materials

1. Read the practical guide.
2. Apply the checklist to the proposed data collection process.
3. Review the before-and-after examples.
4. Refer to the technical report for the project's methodology, findings and limitations.

## Tools and Technologies

- Web-based research
- Markdown documentation
- Git and GitHub
- Document editing and PDF export
- Video recording

## Limitations

The examples are fictional and are not the results of an institutional audit. The project does not claim a formal legal compliance assessment or measured reduction in privacy risk.
